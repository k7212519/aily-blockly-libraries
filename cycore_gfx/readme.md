# Cycore Display

面向 `esp32:esp32:wifiduino32s3` 的 ST7789 八针 SPI 显示库，支持 240×240 与 240×320。

默认接线：SCK 12、MOSI 11、CS 10、RST 17、DC 18、BL 21；电压 3.3V，MISO 不连接。屏幕与 ESP32-S3 必须共地。

绘图先写入 PSRAM RGB565 画布，不会立即改变屏幕。调用“刷新整个显示屏”“刷新显示区域”，或使用“绘制一帧”容器后才批量发送。初始化固定使用旋转 0、32MHz；可通过独立积木修改旋转或选择 20/32/40MHz。改变旋转会按新的逻辑宽高重建并清空画布。

本库只支持本地图片或 RGB565/二维像素数据，不支持 URL、网络、SD 卡和运行时文件加载。若 PSRAM 与内部 RAM 均无法容纳画布，“显示屏已就绪”返回 false，后续绘图与刷新会安全跳过。
