# 芯云 NES 模拟器

面向 `esp32:esp32:wifiduino32s3` 的 Nofrendo NES 模拟器。ROM 可以在编译前通过积木选择并预置进固件，也可以在运行时通过开发板的 Wi-Fi 上传网页写入 FFat；两种来源最终都出现在同一个 Flash 游戏列表中，不需要 USB U盘模式或 SD 卡。

## Flash 分区与文件

使用 Cycore Blockly 默认的 `app3M_fat9M_16MB`：3 MB APP、约 9.9 MB FFat 和系统数据。

- 游戏：`/nes/*.nes`
- 电池存档和即时存档：`/nes/saves`
- 预置 ROM：同时占用 APP 和 FFat；仅在内容变化时重新写入 FFat。
- Wi-Fi 上传 ROM：只占用 FFat。

单个预置 ROM 最多 1.75 MB。由于模拟器本身也占用 APP，多个预置 ROM 的总大小必须小于编译时显示的 APP 剩余容量。Wi-Fi 上传单个 ROM 最多 8 MB，并受 FFat 剩余空间限制。

## 方法一：编译前预置 ROM

1. 放置“初始化NES Flash存储”积木。
2. 放置一个或多个“预置NES游戏”积木，点击字段并选择合法的 `.nes` 文件。
3. 编译烧录。ROM 字节会成为 APP 中的只读数据。
4. 开发板首次运行时自动校验文件，并复制到 `/nes`。以后启动若内容和大小一致就直接跳过，不会反复擦写 Flash。
5. 打开游戏选择列表并启动游戏。

这种方式最适合没有手机、课堂电脑不便切换网络的学生：烧录完成即可运行。更新预置 ROM 后重新编译烧录即可，库会在下次启动时更新 FFat 文件。

## 方法二：Wi-Fi 网页上传

1. 初始化显示屏（可选，用于显示热点名和网址）和 Flash。
2. 执行“开启WiFi ROM上传”积木。默认热点为 `Cycore-NES`，密码为 `12345678`。
3. 电脑连接该热点，浏览器打开 `http://192.168.4.1`。
4. 选择一个或多个 `.nes` 文件并上传。
5. 点击网页中的“完成并进入游戏列表”，开发板关闭热点、刷新 FFat 游戏列表并继续程序。

等待时间设为 `0` 时会一直等待网页点击完成。为了让已有游戏直接启动，可以把 Wi-Fi 上传积木放进“启动时按住某个按键”的条件中，或者设置一个非零超时。

## 推荐积木流程

```text
初始化NES Flash
预置NES游戏（可放多个）
初始化显示屏
设置按键和音频
可选：启动WiFi ROM上传
打开Flash NES游戏选择列表 → 从Flash启动NES游戏
```

游戏列表中方向键用于选择/翻页，A 启动，B 返回。游戏中按 A+B 打开菜单；左+右为 Select，上+下为 Start。

## 硬件要求

- Wifiduino 32S3，16 MB Flash，启用 OPI PSRAM。
- 分区方案 `16M Flash (3MB APP/9.9MB FATFS)`。
- ST7789 240×240，或 240×320 横屏。
- 六个按钮接 GPIO 与 GND，使用内部上拉。
- 可选 MAX98357A 等 I2S 功放。

只上传和使用你有合法权利使用的 ROM。
